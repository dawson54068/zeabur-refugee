# Security Policy

## Supported Versions

This project is a documentation-first rescue guide and Claude Code skill. Security updates apply to the current `main` branch and the latest packaged `zeabur-refugee.skill` release.

| Version | Supported |
| ------- | --------- |
| `main` / latest package | :white_check_mark: |
| Older snapshots | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.** Public disclosure before a fix is available can put users at risk.

Use GitHub's private vulnerability reporting if it is enabled for this repository: open the repository on GitHub, go to **Security → Advisories**, and choose **Report a vulnerability**.

If private vulnerability reporting is not available, open a minimal public issue asking for a private maintainer contact path. Do not include exploit details, credentials, tokens, database URLs, `.env` values, or private user data in the public issue.

Please include privately:

- A description of the issue and its impact
- Steps to reproduce, with secrets redacted
- Affected files or versions
- Any suggested mitigation

## What to expect

- We will acknowledge reports as soon as reasonably possible.
- We will investigate and keep you updated on progress.
- We will coordinate a fix and disclosure timeline with you, and credit you if you wish once the fix is released.

Thank you for helping keep zeabur-refugee and its users safe.
